# Artificial Intelligence — Course Repository

Repository ini merupakan tempat penyimpanan, pengembangan, dan dokumentasi proyek untuk mata kuliah **Artificial Intelligence (AI)**. Repository ini bertujuan untuk mempelajari konsep dasar kecerdasan buatan melalui implementasi sistem pakar, algoritma pencarian, dan sistem multi-agen, serta kolaborasi pengembangan perangkat lunak menggunakan Git dan GitHub.

## 📌 Project Overview

Repository ini mencakup tiga topik utama dalam pembelajaran Artificial Intelligence.

### 1. Expert System

Expert System atau sistem pakar merupakan sistem berbasis kecerdasan buatan yang menggunakan pengetahuan dan aturan tertentu untuk menghasilkan kesimpulan atau rekomendasi berdasarkan fakta dan masukan pengguna.

**Learning Objectives:**
- Memahami konsep dasar sistem pakar.
- Mengimplementasikan aturan berbasis pengetahuan (*rule-based system*).
- Mengolah fakta dan masukan pengguna untuk menghasilkan kesimpulan.
- Memahami proses pengambilan keputusan dalam sistem berbasis AI.

### 2. Search Algorithm

Search Algorithm atau algoritma pencarian merupakan metode yang digunakan untuk menemukan data, mencari solusi, atau menentukan jalur menuju tujuan berdasarkan strategi pencarian tertentu.

**Learning Objectives:**
- Memahami konsep dasar algoritma pencarian.
- Mengimplementasikan strategi pencarian dalam program.
- Menganalisis proses dan hasil pencarian.
- Memahami penerapan algoritma pencarian dalam penyelesaian masalah AI.

### 3. Multi-Agent System (MAS)

Multi-Agent System (MAS) merupakan sistem yang terdiri dari beberapa agen yang berinteraksi dan bekerja sama untuk mencapai tujuan tertentu. Setiap agen dapat memiliki peran dan tanggung jawab yang berbeda dalam menyelesaikan suatu permasalahan.

Dalam repository ini, MAS diimplementasikan melalui simulasi kerja sama beberapa agen, yaitu Planner Agent yang merencanakan dan membagi tugas, Worker Agent yang mengerjakan tugas, serta Evaluator Agent yang memeriksa hasil pekerjaan.

**Learning Objectives:**
- Memahami konsep dasar Multi-Agent System.
- Memahami peran dan tanggung jawab setiap agen.
- Mengimplementasikan pembagian tugas dan kerja sama antaragen.
- Memahami proses evaluasi hasil pekerjaan dalam sistem multi-agen.
- Mempelajari penerapan MAS untuk menyelesaikan masalah secara terstruktur.

## 🚀 Getting Started

Ikuti langkah berikut untuk mendapatkan dan menjalankan proyek.

### 1. Clone Repository

```bash
git clone <URL_REPOSITORY>
```

Ganti `<URL_REPOSITORY>` dengan URL repository GitHub kelompok.

### 2. Masuk ke Folder Repository

```bash
cd Course-Artificial-Intelligence
```

### 3. Pilih Proyek

Pilih folder sesuai program yang ingin dijalankan:

- `Expert-System/` untuk proyek sistem pakar.
- `Search_Algorithm/` untuk proyek algoritma pencarian.
- `Multi_Agent_System/` untuk proyek sistem multi-agen.

### 4. Jalankan Program

Pastikan Python 3 sudah terpasang apabila program menggunakan Python.

Untuk menjalankan Multi-Agent System:

```bash
cd Multi_Agent_System
python main.py
```

Pada beberapa sistem, gunakan perintah berikut:

```bash
python3 main.py
```

Untuk proyek lainnya, jalankan file Python sesuai nama file yang tersedia di masing-masing folder.
